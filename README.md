# Our Little Journey ♡ — An Illustrated React Storybook

A romantic, Studio Ghibli & anime-inspired interactive storybook built with **React**, **React Router DOM**, **Framer Motion**, and **Tailwind CSS**.

Featuring 12 chronological illustrated chapters with **physical 3D page turns**, interactive cat mascots, Web Audio synthesizers, and the sunset finale letter from Rex.

---

## ✨ Features

- 📖 **12 Distinct Chapter Pages**: Individual routing (`#/chapter/1` through `#/chapter/12` and `#/sunset`) with smooth `<AnimatePresence mode="wait">` transitions.
- 🔄 **Realistic 3D Book Page Turns**: Center-spine pivoted rotation with dynamic paper curl highlight ridges, cast shadows, and tactile dog-ear corner peel folds.
- 🐾 **Pervasive Cat Features**:
  - Interactive header cat mascot with twitching ears, blinking eyes, speech bubbles, and meows.
  - Cat pawprint cursor trail following mouse/touch across all pages.
  - Peeking kitten paw in bottom corner that bats playfully, purrs, and emits heart bubbles.
  - Animated walking kitten holding milestone signs along the winding pink trail.
- 🎵 **Zero-Asset Web Audio Engine**: Pure Web Audio API synthesizers for paper rustle, kitten meows, gentle purrs, and a Ghibli music box lullaby.
- 📸 **Custom Photo Memories**: 12 personalized story chapters and the final sunset keepsake letter from Rex.

## 🚀 Running the Project

### 1. Development Mode
```bash
npm install
npm run dev
```
Open `http://localhost:5173/` in your browser.

### 2. Production Build
```bash
npm run build
npm run preview
```

### 3. Standalone Preview
Open `our_journey_react_app.html` directly in any web browser without needing Node.js or a web server.
